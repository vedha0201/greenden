# 🌿 Arbelle Plants

**Arbelle Plants** is a modern and user-friendly plant-selling website designed to help users explore and purchase a variety of plants online. The website provides a simple shopping experience with a clean and attractive interface.

## 🌱 About the Project

Arbelle Plants is an e-commerce style website created for selling plants online. Users can browse different plants, view plant details, and explore the available products through an easy-to-use interface.

The project focuses on creating a visually appealing and responsive frontend for an online plant store.

## 🎯 Project Objective

The main objective of Arbelle Plants is to develop a simple online platform where users can explore and shop for plants while experiencing a clean and responsive website interface.
